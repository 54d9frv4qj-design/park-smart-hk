# 🎨 泊得好 Park Smart HK — 網站線框圖

## 設計規範

### 顏色
- 主色（深藍）：`#1B3A5C`
- 強調色（青）：`#00A8B5`
- 背景：`#FFFFFF`
- 次要背景：`#F0F4F8`
- 狀態綠：`#2ECC71`
- 狀態黃：`#F1C40F`
- 狀態紅：`#E74C3C`

### 字級
- 頁面標題：28px / Bold / #1B3A5C
- 區塊標題：20px / Bold / #1B3A5C
- 正文：14px / Regular / #333
- 小字：12px / Regular / #888
- 統計數字：32px / Bold

### 響應式
- 桌面（>1024px）：多欄布局
- 平板（768-1024px）：兩欄布局
- 手機（<768px）：單欄布局，側邊欄收起
