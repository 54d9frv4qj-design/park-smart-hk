# 📖 泊得好 Park Smart HK — 網站使用說明

## 快速開始

1. 打開網站，進入**首頁**
2. 在搜尋欄輸入地區或停車場名稱
3. 查看統計卡了解全港狀況
4. 點擊地圖上的停車場查看詳情
5. 使用 AI 對話獲取個性化建議

---

## 頁面說明

### 🏠 首頁（Home）

**功能**：
- 搜尋欄：輸入停車場名稱、地址或地區
- 統計卡：全港停車場總數、總車位、平均佔用率、狀態分佈
- 全港地圖：停車場分佈預覽
- Top 5：最易泊 / 最緊張地區排名

**使用技巧**：
- 輸入「旺角」可篩選旺角區所有停車場
- 輸入「天星」可搜尋含「天星」的停車場
- 左側邊欄可快速跳轉到其他頁面

---

### 🗺️ 實時地圖（Real-time Map）

**功能**：
- 全港 607+ 停車場 CircleMarker
- 顏色編碼：🟢 充足 / 🟡 偏緊 / 🔴 滿座
- Popup 含即時空位、30/60 分鐘預測、收費
- 側邊欄篩選：地區、狀態、收費範圍
- 可切換「標記地圖」與「熱力圖」

**使用技巧**：
- 點擊停車場標記查看詳細 Popup
- 滾輪縮放地圖，拖動移動
- 勾選「顯示路邊咪錶」可疊加咪錶數據
- 熱力圖模式可一眼看出邊區最擠

---

### 📋 停車場詳情（Parking Detail）

**功能**：
- 即時狀態大卡片（空位/總數/佔用率/狀態）
- 未來 30/60 分鐘預測
- 24 小時歷史走勢圖
- 7×24 繁忙熱力圖
- 附近 5 個替代停車場
- AI 自然語言泊車建議
- Google Maps / Waze 導航按鈕

**使用技巧**：
- 從下拉選單選擇停車場
- 查看 7×24 熱力圖，避開繁忙時段
- 滿座時直接看替代停車場
- 點擊導航按鈕直接跳轉到導航 App

---

### 💬 AI 對話（AI Chat）

**功能**：
- 自然語言對話界面
- 5 個快捷問題按鈕
- 港式繁體中文回應
- 顯示解析細節（意圖、信心、實體）

**快捷問題**：
1. 「而家旺角邊度有位泊？」
2. 「中環邊個停車場最平？」
3. 「30分鐘後銅鑼灣會唔會滿？」
4. 「附近有冇路邊咪錶？」
5. 「今晚夜泊邊度抵？」

**對話技巧**：
- 直接講地區名就得：「旺角」「中環」「銅鑼灣」
- 可以問收費：「邊個最平？」「時租幾多？」
- 可以問預測：「30分鐘後會唔會滿？」
- 可以問咪錶：「附近有冇路邊咪錶？」
- 可以問夜泊：「今晚邊度夜泊抵？」

---

### ⏱️ 路邊咪錶（Meter Parking）

**功能**：
- 咪錶地圖 / 列表 / 對比 三種模式
- 實時佔用狀態
- 收費資訊（時租、最長泊車時間）
- 咪錶 vs 停車場對比圖

**使用技巧**：
- 短時間泊車（<2小時）優先考慮咪錶，通常較平
- 長時間泊車考慮停車場日租
- 留意咪錶最長泊車時間限制
- 標示「插值」的數據為估算，僅供參考

---

### 📊 儀表板（Dashboard）

**功能**：
- 全港統計數字
- 18 區排名（由易泊到緊張）
- 7×24 時段熱力圖
- 14 天趨勢走勢
- 模型表現對比

**使用技巧**：
- 看 7×24 熱力圖，規劃泊車時間
- 看地區排名，避開最緊張的區
- 看 14 天趨勢，了解長期變化

---

### 💰 收費比較（Fee Comparison）

**功能**：
- 26 個政府場真實收費 + 581 個估計
- 並列顯示時租、日租、月票、夜泊
- 篩選：地區、收費類型、政府場/估計
- 排序：由平到貴 / 由貴到平
- 最抵泊推薦

**使用技巧**：
- 標示「⚠️ 估計」的收費為模型推算
- 政府場收費通常較穩定
- 日租 = 時租 × 6-10，長時間泊車日租更抵
- 夜泊通常 8PM 開始，比時租划算

---

### ℹ️ 關於（About）

**功能**：
- 項目介紹與品牌故事
- 香港泊車痛點分析
- 數據來源說明
- 技術棧詳解
- 免責聲明

## 搜尋技巧

| 想搵咩 | 點樣輸入 |
|--------|----------|
| 某個停車場 | 輸入停車場名稱，如「新世紀廣場」 |
| 某個地區 | 輸入地區名，如「旺角」「中環」 |
| 某條街 | 輸入街道名，如「彌敦道」 |
| 最平 | 用收費比較頁，按時租排序 |
| 最易泊 | 看首頁 Top 5 或儀表板排名 |
| 有 EV 充電 | 在停車場詳情頁查看 has_ev_charging |

## FAQ

**Q：數據幾耐更新一次？**
A：政府 API 每 5-15 分鐘更新，本系統每小時同步，App 內每 10 分鐘刷新。

**Q：預測準唔準？**
A：30 分鐘預測 MAE 約 3 個位，60 分鐘約 4.5 個位。實際情況可能因突發事件偏離。

**Q：點解有啲停車場收費標示「估計」？**
A：政府只公開 26 個停車場的真實收費，其餘 581 個由模型根據地區、車位數等估算。

**Q：咪錶數據點解有時缺失？**
A：部分舊式咪錶無實時傳感器，我哋用同街道空間插值估算，會標註「插值」。

**Q：可以離線用嗎？**
A：可以！系統內建模擬數據生成器，API 失敗時自動降級，確保功能可用。

**Q：點解要用 /tmp/ 路徑？**
A：Streamlit Cloud 的 /mount/src/ 是唯讀的，DB 和模型必須放在可寫的 /tmp/。
